## What the product is
- source: /Users/koss/Developer/ui-system/README.md; /Users/koss/Developer/ui-system/CLAUDE.md
- Brand-agnostic design system. One `ui.config.json` per project drives colors, radius, type, logo and navigation; nothing client-specific is baked into defaults.
- Pipeline: `ui.config.json` → `@ui-system/core` → theme.css, tailwind.css, tokens.json, theme.json; → `@ui-system/react` → apps; → `uis.bundle.js` (`window.UIS`) → Claude Design canvases.
- Live playground: https://loomlyne.github.io/ui-system/ (GitHub Pages, `pages.yml`). License MIT.

## Using UI System per stack
- source: /Users/koss/Developer/ui-system/docs/frameworks.md (untouched since 2026-09-27)
- Next.js: `<Root config>` in app/layout; zero-JS via theme.css + `vars={false}`; dark via config mode or `data-uis-mode="dark"`.
- Tailwind v4: import theme.css + tailwind.css; utilities `bg-surface`, `rounded-control`, `h-control-md`, `dark:` tied to `data-uis-mode`.
- Plain HTML: theme.css + ui.css from jsDelivr (`cdn.jsdelivr.net/gh/Loomlyne/ui-system@main/...`), class API `uis-btn`, `uis-card`, `uis-bar`, etc.
- Framer: paste CSS into head, or code components wrapping `Root`; map theme.json to colour styles.
- Shopify OS 2.0: theme.css + ui.css in assets; header built with `uis-stacked` markup.
